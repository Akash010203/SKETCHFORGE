# Dataset card

## Current data

The first local workflow uses original synthetic sketch fixtures in `assets/sample_sketches/`. These are generated within this project and are separate from external human-created datasets.

## External candidates

Candidate sources, pinned metadata, access conditions, license notes, storage estimates, and exclusions are recorded in `DATASET_AUDIT.md` and `../datasets/manifests/manifest.json`. No external dataset has been approved for training or downloaded. Recheck upstream terms before changing that status.

## Intended use and limitations

Synthetic fixtures support reproducible pipeline and evaluation work. They do not establish performance on real hand-drawn sketches. Keep synthetic and real evaluation results separate.
